# Bundled engraving font

Unmodified Noto Sans CJK TC Regular, Noto Sans CJK release **2.004**.

Source: https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/OTF/TraditionalChinese/NotoSansCJKtc-Regular.otf

License: SIL Open Font License 1.1; see `OFL.txt` from the same release.
Copyright © 2014–2021 Adobe (http://www.adobe.com/).
Copyright notices and original font naming are retained in the unmodified font name table.
SHA-256: `dce08bd4fd91aa8aa76ed8fea4b694c2dfb8550f67871e326843212ddbeb88b4`.

Parsed locally with opentype.js 1.3.4 (MIT, license distributed in its npm package).
No user text is sent to a font service; the asset URL is constant and same-origin.
The font is used only for requested engraving vectors, not application typography.
