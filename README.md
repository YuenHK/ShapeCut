# ShapeCut

ShapeCut 是一個在瀏覽器內將 STL 轉成通用 Laser Cut 外形切片的一鍵工具。檔案只在本機處理，不會上載到伺服器。

## 開始使用

需要 Node.js 20 或以上版本。

```bash
npm install
npm run dev
```

開啟頁面後，只需拖放 STL 或按「選擇模型」。選擇檔案會立即開始完整流程：

- 「成功 · 精確切片」：安全模型已沿可信軸心完成精確切片。
- 「需注意 · 精確切片」：幾何仍是精確切片，但軸心來自最短包圍盒回退；這不表示已進行 2.5D 簡化。
- 「需注意 · 2.5D 外形」：已自動使用近似外形；細小分離零件會被移除，不可靠的孔洞或深淺特徵會被省略。
- 「失敗」：檔案無法讀取、沒有有效外形，或超出時間／資源上限；可立即選擇另一個檔案。

成功或需注意時，頁面會提供五個下載：ZIP 製作套件、SVG、DXF、平面預覽 PDF 及爆炸圖 PDF。ZIP 內四項檔案與四個個別下載逐 byte 相同，並以同一組來源及特徵 fingerprint 對齊。

輸出使用三種固定顏色表示相對角色：

- 黑色：切割外框，以及通過可靠性規則的中央孔。
- 紅色：相對較深層特徵。
- 藍色：相對較淺層特徵。

中央孔必須是有限、簡單、閉合、完全位於外框內並保留所需間距的近軸孔；其等效直徑亦須至少為 `max(0.5 mm, 該層寬度的 1%)`。不符合任何一項便會省略並顯示提示，不會強行產生切割線。顏色只表示相對層級，並不是雷射功率、速度或走刀次數。

處理中及完成畫面會顯示真實網格和分層爆炸圖。偏好 reduced motion 時會停用自動旋轉並直接顯示目前階段；WebGL 不可用或建立失敗時會改用靜態 SVG 預覽，下載內容不受影響。

## 開發與驗證

```bash
npm test
npm run test:browser
npm run test:e2e
npm run validate:fixtures:public
npm run test:performance
npm run typecheck
npm run build
```

`validate:fixtures` 是發佈用 gate，必須同時提供兩個外部驗收輸入；本機日常開發只驗證公開 fixtures 時，請使用上述獨立的 `validate:fixtures:public` 命令。

Production build 位於 `dist/`。應用包含 Web App Manifest 與只快取同源靜態 shell 的 service worker；使用者選取的 STL 不會進入離線 cache。

## 安全與限制

- 2.5D 是可驗證的外形近似，不是已修復的封閉 3D 實體。
- 每層以最大外輪廓為基礎；只有通過規則的中央孔與相對深淺特徵才會保留，其他孔洞、內部細節和較小斷開零件可能被忽略。
- 實際堆疊高度取決於使用者的材料厚度，不會自動等於模型原高度。
- 工具不提供或認證雷射功率與速度；正式製作前必須根據機器及已確認材料進行少量試切。

更完整的操作要求見 [材料與雷射安全](docs/materials/safety.md)。
