# 切片刻字實作計劃

> 採用 subagent-driven-development 與 test-driven-development；先實作測試，再驗證失敗與通過。保留既有已批准的模型交接功能。

**目標：** 將名稱、作品名及依幾何高度命名的 PartA/B/C 轉為可檢查的向量刻字並輸出。

**架構：** 獨立刻字模組負責輸入正規化、固定字型輪廓及有限次數的弧形排版。匯出器以共同字形資料生成 SVG、DXF、PDF 與 ZIP；UI 與本機儲存傳遞設定，不在 STL 幾何中混入文字。

## 1. 幾何與匯出（獨立子任務）

- [ ] 建立 `src/domain/part-engraving/`，定義 `EngravingSettings = { name: string; workName: string }`，24 Unicode 字元限制、空白正規化及缺字檢查。
- [ ] 先測試 `normalizeEngravingSettings({ name: ' 1A99 ', workName: '破滅魔劍' })` 得到正規化值；空白停用、控制字元拒絕。
- [ ] 加入可合法再散布的固定繁體字型及授權來源；所有執行期資源來自本站，不傳送刻字資料。
- [ ] 測試弧形字形、3 mm em 高度、1 mm 切割間距、孔位與裝飾避讓、過長失敗及依 z 高度命名。
- [ ] 實作有計算上限的排版；共用輪廓輸出至獨立 `ENGRAVE_TEXT` 圖層，加入套件一致性驗證，維持舊無刻字輸出。
- [ ] `createOutlinePackage` 第三參數 options 新增可選 `engraving`；未提供或空白沿用原行為。同步 verify 路徑。
- [ ] 執行新增幾何及匯出測試、原匯出測試；分別審查規格及程式品質。

## 2. UI、Worker 與本機設定（主代理）

- [ ] `OneClickConverter` 加兩欄、選填及私隱／試刻提示；沿用原控制項樣式。
- [ ] `services.package(result, fileName, engraving?)` 與 worker `packageOutline(result, deadline?, engraving?)` 傳遞設定，舊呼叫相容。
- [ ] 在本機專案記錄中加入可選 engraving 設定；舊資料無此欄等同關閉，捨棄時清除。
- [ ] 先測試輸入傳遞、重開恢復及清除，再實作；重新刻字不重新處理 STL。
- [ ] 結果页顯示真正輸出的刻字向量預覽。失敗時阻止下載並可修改刻字，保留已計算結果。

## 3. 驗收與部署

- [ ] `npm run typecheck`、`npm test`、`npm run build`，區分原有失敗與新增失敗。
- [ ] Playwright 使用 sample1/sample2 與 `1A99 破滅魔劍`；核對成功或明確空間不足，不靜默漏字。
- [ ] 桌面／手機截圖、切割輪廓不變、各格式字形一致、空白輸入回歸測試。
- [ ] 更新中文說明、字型授權及雕刻圖層使用方式。
- [ ] 提交、推送 GitHub，等待部署成功，正式網址重測。實物試刻列為用家驗收，不宣稱已完成。
