# ShapeCut 平衡留白 UI 設計規格

## 目標

改善主頁左側文字的視覺層級與運算畫面的空間感，同時保留現有功能、字體、字級系統及配色。新版採用已確認的「B｜平衡留白」方向。

## 主頁左欄

- 眉題顯示「3D → LASER CUT」
- 主標題固定為三行：
  1. 「把陀螺模型」
  2. 「變成可製作的」
  3. 「三層切片」
- 副標題改為：「從 STL 到 Laser Cut 製作檔案，一次完成分析、簡化與分層。」
- 主標題使用現有標題字體、字重及色彩，僅調整桌面版的最大寬度、行高、斷行及段落間距。
- 眉題、主標題與副標題之間使用三段清晰的垂直留白，副標題不貼近主標題。
- 左欄內容在欄內垂直置中，與右側上載區形成均衡的雙欄構圖。
- 手機版取消強制三行斷句，讓文字按可用寬度自然換行，避免水平溢出。

## 運算畫面

- 保留左側模型即時預覽、右側運算狀態、底部進度條及獨立「更換模型」按鈕。
- 右側圓形狀態環較現版稍大，並限制於狀態卡可用範圍內。
- 圓內依次顯示：處理階段標題、檔名、已處理時間及「取消處理」按鈕。
- 四項內容必須完全位於圓形安全邊界內；長檔名須截短或換行，不可撐破圓環。
- 圓環與進度條、進度條與「更換模型」按鈕之間增加垂直距離，三者形成清晰分組。
- 手機版仍保持內容不越界、不產生水平捲動，並保留取消及更換模型操作。

## 不變範圍

- 不修改材料選項、三層切片邏輯、三爪孔幾何、STL 運算流程或輸出格式。
- 不更改現有按鈕功能、字體家族、色彩 token 或動效語意。
- 不移除 GitHub 專案介紹及陀螺對戰模擬器連結。

## 驗收標準

- 1280 × 720、1024 × 768 及 390 × 844 畫面沒有水平溢出。
- 桌面主標題按指定文字固定三行，副標題與主標題之間有清楚留白。
- 真實瀏覽器量度確認圓內標題、檔名、時間及取消按鈕四邊均位於圓形安全界線內。
- 運算圓環、進度條及更換模型按鈕互不重疊，並保有可見間距。
- 單元測試、瀏覽器測試、生產建置及 GitHub release gates 全部通過後才部署。
