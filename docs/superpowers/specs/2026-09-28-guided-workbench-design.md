# ShapeCut 引導式製作工作台

## 批准與邊界

使用者已確認兩張概念圖、版面及後續實作。沿用全部 STL 運算、指紋驗證、三爪樣板、刻字向量、持久化及匯出安全檢查；不添加概念圖的相機工具，不以渲染圖片替代實際模型。保留既有藍白識別；已批准的改版範圍包括標題比例、留白及減少裝飾，不改其他頁的功能。

## 設定與製作

- 桌面左右固定工作台：左側真實模型預覽約 60%，右側設定／進度約 40%；標題不以檔名佔據大幅高度。
- 材料先於刻字；刻字兩欄、驗證及授權保留，增加純文字範例，不冒充已計算的向量結果。
- 三爪微調移入原生可鍵盤操作的「進階配合設定」，收合時顯示數值，非法值時自動可見或有明確錯誤提示。
- 操作列位於工作台底部，與設定捲動區分離：更換模型／重新連結、材料摘要、開始製作。主要操作在 1280×720 及 1440×900 可見且無需先捲動設定。
- 運算使用同樣預覽／右側進度／底部取消及更換模型位置；保留階段、計時、取消，不顯示虛構百分比，不增加動畫計算負擔。
- 決策不一致保留安全攔截，預覽不消失；右側顯示「需要你的操作」、原因及保留設定資訊。底部提供重新連結原模型，指紋驗證完成後才可開始。
- 四階段路標：模型、設定、製作、下載；保留目前步驟及可及性播報，僅為狀態指示，不允許跳過驗證。
- 不改首頁與下載頁的既有行為；本次落實兩張批准概念圖的設定、製作及恢復狀態。其他格式、預覽及原下載仍保留。

## 手機與可及性

390px 單欄，允許內容自然捲動；底部操作使用 sticky 且不遮擋焦點。控制項至少 44px，保留文字、鍵盤與 reduced-motion 支援。不使用只有圖示的主要操作。無資料時顯示預覽佔位，不杜撰幾何。

## 驗收

單元測試確認相同服務呼叫、儲存與恢復流程；瀏覽器以新檔、儲存專案、外框不一致、非法微調、刻字、取消、替換模型測試。檢查 1280×720、1440×900、390×844，主要操作固定可達且無橫向溢出。實際 sample1 轉換、刻字、重新連結與 ZIP 下載，公開站部署後重測。軟件驗收不等於實物切割認證。
