# 3D Print To Laser Cut 操作示範影片設計

日期：2026-07-20

## 目標

製作一段約 3 分鐘的 1080p MP4 操作示範，讓首次接觸本工具的使用者理解如何把 STL 模型轉換成可供雷射切割及雕刻的輸出套件，同時理解模型拓撲與材料校準的安全限制。

## 已批准形式

- 採用網站真實操作錄影，不以靜態投影片模擬操作。
- 使用繁體中文字幕與畫面重點提示，不設旁白。
- 配上輕柔、可合法隨影片發佈的背景音樂；音量不得影響閱讀節奏。
- 輸出 1920×1080、約 3 分鐘的 MP4。
- 示範標準陀螺的完整成功流程，再簡短展示 Knight Fortress STL 的診斷、修復結果及安全阻擋。

## 故事板

### 1. 片頭（約 0:00–0:12）

- 顯示工具名稱與一句用途說明：「把 3D 模型轉換成 Laser Cut 分件及雕刻圖層」。
- 提示所有模型處理均在使用者的本機瀏覽器內進行。

### 2. 匯入標準模型（約 0:12–0:35）

- 選取專案內可完整通過流程的標準陀螺 STL。
- 顯示匯入、解析及模型檢查狀態。
- 字幕指出 STL 單位與模型完整性會影響結果。

### 3. 模型預覽與軸線（約 0:35–1:00）

- 展示 3D 預覽、旋轉模型及問題標記。
- 展示自動旋轉軸結果；說明低對稱模型需要使用者確認手動軸線。

### 4. 材料及分件（約 1:00–1:35）

- 選擇材料設定，展示厚度、切縫及校準狀態。
- 執行自動分件，顯示環、輪轂、肋件或相關組件。
- 明確指出預設材料資料不可直接當成生產參數，正式切割前必須完成材料測試片及操作員確認。

### 5. 紋理雕刻與輸出（約 1:35–2:10）

- 展示模型深淺紋理轉換成分級雕刻圖層。
- 顯示 CUT 與 ENGRAVE 圖層、排版及組裝次序。
- 展示可輸出的 SVG、DXF、PDF、JSON 與 ZIP 套件；避免在未符合安全條件時暗示可直接生產。

### 6. Knight Fortress 實例（約 2:10–2:45）

- 匯入使用者提供的 Knight Fortress STL，但不得將該檔案提交至 Git。
- 展示工具能讀取模型，而不是籠統顯示「讀不到檔案」。
- 顯示偵測到的退化面、未解決拓撲或其他真實診斷，以及安全／進階修復結果。
- 強調即使能下載修復後 STL，未通過拓撲驗證仍不會解鎖正式切片或生產輸出。

### 7. 片尾（約 2:45–3:00）

- 總結三步：「檢查模型 → 校準材料 → 預覽後輸出」。
- 顯示安全提示：「先製作材料測試片，再進行正式 Laser Cut」。

## 視覺與字幕規格

- 中文字幕使用高對比底色，保持在安全邊界內，不遮擋主要按鈕及模型問題標記。
- 游標移動保持平穩；重要操作可使用短暫放大、框線或停頓提示。
- 刪除等待、重複點擊及非示範所需的畫面，保持連續而真實的操作節奏。
- 模型名稱、材料狀態、阻擋原因及輸出格式必須與網站實際顯示一致，不加入網站沒有提供的能力。

## 製作流程

1. 在本機啟動 production-equivalent 網站。
2. 以固定 1920×1080 viewport 錄製標準模型與 Knight Fortress 兩段真實操作。
3. 剪輯為約 3 分鐘，加入字幕、重點提示、片頭片尾及合法背景音樂。
4. 輸出 MP4，另保留無音樂版本作後備。
5. 逐段檢查字幕、模型狀態、材料警告、畫面清晰度、音量及最終影片可播放性。

## 驗收標準

- MP4 可正常播放，解析度為 1920×1080，總長度目標為 2:40–3:20。
- 標準模型流程包含匯入、軸線、材料、分件、雕刻預覽及輸出。
- Knight Fortress 段落顯示具體診斷與安全阻擋，不聲稱問題已完全修復。
- 全片使用繁體中文字幕、沒有旁白，並有不妨礙觀看的背景音樂。
- 不洩漏本機路徑、電郵地址、帳戶資料或其他個人資訊。
- 使用者提供的 STL 保留於本機，不加入 Git commit 或公開資產。
