# ShapeCut 寬鬆工作台 UI 規格

## 目標

在桌面視窗內保留所有主要功能，同時以更清晰的留白和左右分區，減少控制項擠迫及運算畫面被狀態卡遮擋的感覺。

## 已確認設計

- 保留現有藍白配色、字體、字級與控制項文字。
- 主頁使用左右雙欄：左側說明，右側大型上載區；範例模型及功能說明置於下方。
- 桌面工作台採用較寬容器，主要卡片四周至少 24px 留白，雙欄距離為 40px。
- 有模型預覽的運算畫面使用約 2:1 雙欄：左側大型預覽，右側狀態、已用時間、進度及取消操作。
- 「更換模型」獨立置於右側狀態欄底部，不覆蓋預覽。
- 手機版維持中央狀態卡，避免狹窄畫面形成過細雙欄。
- 首頁只保留 sample1、sample2 兩個範例。

## 驗收

- 1280 × 720 桌面視窗無整頁垂直捲動。
- 主頁工作台內距 24px、卡片左右內距 32px、雙欄距離 40px。
- 運算預覽寬度至少為狀態欄的 1.5 倍，而且兩者互不重疊。
- 390 × 844 手機畫面沒有水平溢出，狀態卡仍置中且更換模型按鈕可見。
