## 技術敘述界線

- 瀏覽器是目前正式執行環境；STL 不上傳到 ShapeCut 後端或 GitHub Pages。
- 自動軸心優先採用可信候選，否則使用最短包圍盒軸並顯示提示。
- 固定輸出三個來源軸向區段：下、中、上；來源取樣跨度不等同材料厚度。
- 安全修復通過才可走精確切片；否則使用原模型的 2.5D 投影回退並明確標示。
- 中央孔及深淺特徵只有通過有限、閉合、包含、距離及可靠性規則才保留。
- 三爪幾何為三組相同圓邊輪廓，等距 120 度；kerf 與可調配合偏移納入規劃，結構衝突須安全停止或省略不可靠的可選幾何。
- Rust/WASM 與 Web Workers 的實際發布路徑按目前證據說明；不得把測試中的 WASM 能力寫成 production 已全面採用。
- 效能數字必須標示測試日期、環境與量測範圍，不推論所有裝置都會獲得相同比例。
