# ShapeCut 無自動超時與中央讀取動畫設計

## 目標

讓合格但較複雜的 STL（包括加入官方三爪孔的 Knight Fortress）不會因固定處理時間而自動失敗；處理期間以穩定、清晰的中央讀取畫面回饋進度。

## 處理限制

- 移除自動轉換與輸出封裝的固定 runtime deadline。
- 保留使用者主動取消能力；取消必須在現有檢查點停止工作並回到可重新選檔狀態。
- 保留所有資源與製造安全限制：128 MB STL、500,000 三角面、300,000 不重複頂點、最多 24 層、光柵與輪廓預算，以及三爪孔／中心孔／最小連接厚度／碰撞檢查。
- 不把任何資源限制錯誤顯示為時間逾時；只在使用者取消時顯示取消結果。

## 中央讀取介面

- 所有讀取與處理階段使用同一個中央 loading panel。
- 使用方案 B：大型旋轉進度環包圍標題「正在讀取模型」，環上方保留三點節奏提示。
- 檔名下方顯示即時已處理時間，格式為 `已處理 mm:ss`；由選檔後立即開始，完成、失敗或取消時停止。
- 動畫採純 CSS 轉動；計時只每秒更新一次，並與工作執行緒進度更新分離，避免重繪造成閃爍。
- 保留現有無障礙公告：loading panel 不新增重複 live region，計時對讀屏軟體以低頻率公告。

## 驗證

- 單元測試：無自動 deadline、資源限制仍拒絕超額輸入、取消仍會停止。
- 元件測試：中央 B 動畫、`mm:ss` 計時、完成／失敗／取消時停止計時。
- Browser Mode：使用兩個 Knight Fortress STL 驗證可持續處理超過 120 秒而不產生 `TIME_LIMIT`；資源與結構衝突仍受阻擋。
- 建置與完整測試套件通過。
